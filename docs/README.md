# LazyKick documentation

LazyKick is one dockable panel for **Adobe Premiere Pro and After Effects**.
It pastes clipboard images straight onto the timeline, keeps project notes
with timecode stamps, times a written script to the voiceover and turns it
into subtitles, and lets watch folders import new media into your bins by
themselves. It is free, open source and runs entirely on your own computer.

![LazyKick's three tabs: a script timed to the voiceover with the spoken word highlighted, watch bins linked to folders, and the paste options with recent pastes](images/overview.png)
